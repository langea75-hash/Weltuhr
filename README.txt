WELTUHR MIT ANDROID-WIDGET

Enthalten:
- Android-App "Weltuhr"
- Homescreen-Widget
- Berlin, London, Toronto, New York und Tokio
- 24-Stunden-Anzeige
- Sekunden in der App, Minuten im Widget
- automatische Sommer-/Winterzeit über IANA-Zeitzonen
- Tipp auf das Widget öffnet die App

In Android Studio:
1. Ordner "WeltuhrWidget" öffnen.
2. Gradle synchronisieren lassen.
3. App auf dem Android-Handy installieren.
4. Startbildschirm lange drücken -> Widgets -> Weltuhr.
5. Widget auf den Startbildschirm ziehen.

Hinweis:
Diese ZIP enthält den vollständigen Quellcode. Eine APK ist nicht enthalten,
weil in dieser Umgebung kein Android-SDK/Build-System installiert ist.
